入荷読み取り.xlsm の作成手順（開発者が Windows で1回だけ行う作業）
======================================================================

用意するファイル（excel/dist/）
  - 入荷読み取り_template.xlsx
  - modScan.bas
  - ThisWorkbook.txt

1. 入荷読み取り_template.xlsx を Excel で開く。
2. Alt + F11 で VBA エディタを開く。
3. メニュー［ファイル］→［ファイルのインポート］で modScan.bas を選ぶ。
   左側の「標準モジュール」に modScan が追加される。
4. 左側の「ThisWorkbook」をダブルクリックし、ThisWorkbook.txt の内容を
   すべてコピーして貼り付ける。
5. 左側に「shScan (読み取り)」「shData (入荷データ)」と表示されていることを確認する。
   （括弧の前がシートのオブジェクト名。違う場合はプロパティの (オブジェクト名) を修正）
6. メニュー［デバッグ］→［VBAProject のコンパイル］でエラーが出ないことを確認する。
7. VBA エディタを閉じ、［名前を付けて保存］で
   ファイルの種類「Excel マクロ有効ブック (*.xlsm)」、ファイル名「入荷読み取り.xlsm」で保存する。

動作確認
  1. 入荷読み取り.xlsm を開き直す（マクロの有効化を求められたら「コンテンツの有効化」）。
  2. 読み取り欄に手入力で YN34214,10000 と入力して Enter。
     → 結果に「読み取りOK」、入荷データシートに1行追加されることを確認。
  3. 同じ内容をもう一度入力 → 重複確認メッセージが出ることを確認。
  4. ABC と入力 → 赤字のエラー表示とビープ音を確認。
  5. 全角で ＹＮ３４２１４，１００ と入力 → 正しく追加されることを確認。
  6. バーコードスキャナで、処理済みPDFを印刷したもののバーコードを読み取る。

お客様PCへの設置
  - 読み取り用パソコンごとに 入荷読み取り.xlsm を1つずつ配置する（ファイルの共有はしない）。
    各行に「読み取りPC」が記録されるため、後で複数台分をまとめても区別できる。
  - ファイルを信頼できる場所に置くか、ファイルのプロパティで「許可する」(ブロックの解除)に
    チェックを入れる。メール等で受け取った xlsm はマクロがブロックされるため。
  - スキャナは「USBキーボード（HID）モード」「末尾に Enter を付加」の設定で使用する。
