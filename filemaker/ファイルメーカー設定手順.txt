納品書バーコード追加ツール　ファイルメーカー設定手順
====================================================

対象：FileMaker Pro 19（Windows）で納品書PDFを作成しているスクリプト
作業時間：約15分

----------------------------------------------------
1. ツールのインストール（発行を行う各パソコンで1回）
----------------------------------------------------
  共有フォルダの「納品書バーコード」フォルダ内にある install.bat をダブルクリックします。
  「Installed: C:\YukiSoft\nohin_barcode\nohin_barcode.exe」と表示されれば完了です。
  ※ツールを更新した場合も、同じ手順で上書きされます。

----------------------------------------------------
2. スクリプトの修正
----------------------------------------------------
  納品書PDFを作成しているスクリプトを開き、
  「レコードを PDF として保存」ステップの直後に、以下の3ステップを追加します。

  ※下記の $pdfPath は、「レコードを PDF として保存」で出力先に指定している変数です。
    貴社スクリプトで別の変数名を使っている場合は、その変数名に読み替えてください。
    出力先を変数ではなく直接指定している場合は、先に変数へ設定してから
    「レコードを PDF として保存」の出力先にその変数を指定してください。

  (1) 変数を設定
      名前： $winPath
      値　：
        Let ( [
          p = $pdfPath ;
          p = If ( Left ( p ; 8 ) = "filewin:" ; Middle ( p ; 9 ; Length ( p ) ) ; p ) ;
          p = If ( Left ( p ; 1 ) = "/" and Left ( p ; 2 ) ≠ "//" ; Middle ( p ; 2 ; Length ( p ) ) ; p )
        ] ;
          Substitute ( p ; "/" ; "\\" )
        )

      （例）filewin:/C:/Users/abc/Desktop/YN34214.pdf → C:\Users\abc\Desktop\YN34214.pdf
            filewin://server/share/YN34214.pdf       → \\server\share\YN34214.pdf

  (2) イベントを送信
      メッセージ：「ドキュメント/アプリケーションを開く」
      送信内容　：「計算式」を選び、次の式を入力
      計算式：
        "\"C:\\YukiSoft\\nohin_barcode\\nohin_barcode.exe\" \"" & $winPath & "\""
      「ターゲットアプリケーションを前面に表示」：オフ

  (3) スクリプト一時停止/続行
      間隔（秒）： 3
      ※ツールの処理（1〜2秒）が終わってからメール添付に進むための待ち時間です。

  追加後のイメージ：
    レコードを PDF として保存 [ 「$pdfPath」 ; ... ]      ← 既存
    変数を設定 [ $winPath ; 値: Let ( ... ) ]             ← 追加
    イベントを送信 [ "aevt" ; "odoc" ; "\"C:\\YukiSoft\\..." & $winPath & "\"" ]  ← 追加
    スクリプト一時停止/続行 [ 間隔 (秒): 3 ]               ← 追加

----------------------------------------------------
3. 動作確認
----------------------------------------------------
  1. 修正したスクリプトで、納品書PDFを1件作成します。
  2. 作成されたPDFを Acrobat Reader で開きます。
     ※Edge や Chrome で開くと入力欄・バーコードは表示されません。必ず Acrobat Reader で確認してください。
  3. 納品書の「納入数」欄をクリックして数量を入力し、Enter を押します。
     → 部品番号の右側にバーコードが表示され、受領書の「納入数」欄にも同じ数量が表示されれば成功です。

----------------------------------------------------
エラーが表示された場合
----------------------------------------------------
  「納品書PDFへのバーコード追加に失敗しました。このPDFは送付しないでください。」
  と表示された場合は、そのPDFは送付せず、表示内容を控えてユキソフトまでご連絡ください。

  処理の記録（ログ）は次の場所に保存されています。お問い合わせの際にお送りください。
    %LOCALAPPDATA%\YukiSoft\nohin_barcode.log
  （エクスプローラーのアドレス欄に上記を入力すると開けます）

  なお、同じPDFに対してツールが2回実行されても、PDFは変更されません（二重追加はされません）。
